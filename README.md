One letter, A to Z, standing for the word that describes the day. This entry
sends **D** — for *doomscrolling*: the day spent thumbing through bad news
until 2 a.m., phone glow on the ceiling, one more scroll, then one more.
Vivid, specific, funny, and honest about a real modern day.

## How it works

`main.ts` (Node 22, stdlib only) writes exactly one character, `D`, to
`/output/entry.txt` — no trailing newline, no gloss, no punctuation. The
gate requires 1–1 characters, so the file is one byte.

## Run it

```sh
node main.ts /tmp/out
cat /tmp/out/entry.txt   # D
```

## Why D

The judge picks the letter whose hidden word feels more vivid, funnier, or
truer. *Doomscrolling* calls up a sharp picture at once (the phone glow, the
hour getting later), it lands funny because everyone has done it, and it reads
as an honest report of a real day — not a performance, not a vague mood.
